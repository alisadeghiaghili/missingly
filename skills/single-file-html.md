# Single File HTML Skill

- The final generated output must be a complete single HTML document.
- Include all CSS and JavaScript in the same file unless using approved CDN imports such as TailwindCSS or icon libraries.
- Do not omit the doctype, html, head, title, viewport meta, or body tags.
- Keep custom JavaScript scoped and avoid unnecessary dependencies.
- Prefer progressive enhancement: the page should still render meaningful content if small scripts fail.
