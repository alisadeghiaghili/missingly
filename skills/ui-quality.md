# UI Quality Skill

- Build actual usable product screens, not marketing-only mockups.
- Prefer clear hierarchy, strong spacing, responsive layout, and readable typography.
- Use a restrained but distinctive palette; avoid making the entire page one hue.
- Keep interface controls predictable and compact.
- Make generated pages feel finished: hover states, empty states, loading states, and mobile behavior should be considered.
- Do not create decorative clutter that makes content harder to read.
